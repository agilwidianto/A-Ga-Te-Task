## 📌 **Deskripsi Proyek**

**A-Ga-Te-Task** adalah proyek dokumentasi **Quality Assurance (QA)** yang berfokus pada **test planning**, **bug reporting**, dan **evaluasi kualitas aplikasi**.
Repository ini dibuat untuk mempermudah proses pengujian, pencatatan defect, serta menyediakan bukti visual dan analisis hasil QA.

Dokumentasi dalam project ini dapat digunakan sebagai referensi untuk pengujian manual, evaluasi kualitas sistem, dan pembuatan laporan defect.

---

## 🗂️ **Struktur Repository**

```bash
A-Ga-Te-Task/
├── Flowchart.png                     # Diagram alur proses aplikasi atau pengujian
├── Test Script.xlsx                 # Daftar skenario dan langkah-langkah pengujian
├── Bug Report.docx                  # Dokumentasi bug atau defect yang ditemukan
├── Bug Attachment.docx             # Bukti visual berupa screenshot bug
├── QA Report - Agil Widianto.docx   # Laporan hasil Quality Control secara lengkap
└── README.md                       # Dokumentasi utama project
```

---

## 📄 **Penjelasan File**

| **Nama File**                    | **Deskripsi**                                                                   |
| -------------------------------- | ------------------------------------------------------------------------------- |
| `Flowchart.png`                  | Visualisasi alur sistem atau proses pengujian untuk mempermudah pemahaman.      |
| `Test Script.xlsx`               | Skenario pengujian yang dirancang secara terstruktur dan lengkap.               |
| `Bug Report.docx`                | Laporan bug atau defect yang ditemukan selama proses pengujian.                 |
| `Bug Attachment.docx`            | Lampiran bukti visual seperti screenshot untuk mendukung laporan bug.           |
| `QA Report - Agil Widianto.docx` | Laporan hasil pengujian, analisis kualitas aplikasi, dan rekomendasi perbaikan. |

---

## 🎯 **Tujuan Proyek**

1. **Test Planning**
   Menyusun test cases dan skenario pengujian secara lengkap dan terstruktur.
2. **Bug Reporting**
   Mencatat defect dengan detail, termasuk langkah reproduksi dan bukti visual.
3. **Visualisasi Proses**
   Menggunakan flowchart untuk membantu pemahaman alur sistem atau proses testing.
4. **Evaluasi QA**
   Menyediakan laporan lengkap mengenai hasil pengujian dan rekomendasi perbaikan.
